# Security Policy

## Supported Versions

Only the latest release on `main` is supported with security updates.

## Reporting a Vulnerability

**Do not open a public issue for security vulnerabilities.**

Please use [GitHub's private vulnerability reporting](https://github.com/sixteen-dev/obai/security/advisories/new) to report security issues.

You should receive a response within 72 hours. If the vulnerability is confirmed, a fix will be released as soon as possible.
